# Xiazhouqi Travel Cover Skill

专门用于「下周七 / 小岛周末」旅行视频封面的视觉 Skill。

## 风格一句话

**真实旅行照片做主角 + 安静好看的标题字体 + 克制的照片取色 + 轻微人物轮廓光。**

目标不是做“爆款大字报”，而是让封面在手机小图里依然看得清重点，同时保留旅行照片本身的情绪、空气感和人文感。

## 适合内容

- 徒步 / 登山 / 日出日落
- 城市漫游 / 周末旅行
- 旅行 Vlog / 公路 / 海边 / 山野
- 偏记录感、纪实感、人文感的旅行视频

## 默认规则

- 抖音封面默认：**3:4 竖版**
- 照片优先，不为了设计破坏原图
- 主标题清楚，但拒绝“大卖场 / 好物分享 / 粗笔刷爆款字”
- 颜色优先从原照片中提取
- 人物需要分离时，用**很轻的暖白轮廓光**，不要厚贴纸描边
- 装饰尽量少，保持安静和留白

## 使用方式

把 `SKILL.md` 和本次旅行照片一起交给 ChatGPT，然后直接说：

> 按这个 Skill 做一张抖音旅行封面，标题「夜爬泰山」。

详细视觉规则、构图、字体、描边、颜色和自检标准全部写在 `SKILL.md` 中。
